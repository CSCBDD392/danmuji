# 弹幕点歌机 · 弹幕面板

PC 端两只小工具：**一个聚合入口，两个各自能独立跑的东西**。

1. **点歌机**（`main.py`）—— 监听 B 站直播间弹幕，观众发「点歌 晴天」，自动去**酷狗 / 网易云 / QQ音乐**三家里搜到最像的那首并播放。
2. **弹幕面板**（`danmu.py`）—— 从 B 站抓弹幕，实时显示在一个**正方形面板**里，面板可以贴在任意窗口的左/右边缘，也可自由拖动、投到别的显示器。

它俩只靠一个本地 TCP 端口（默认 9701）松耦合：**谁关了另一个都照常工作**。
点歌机播歌时顺手推一行「▶ 点播《晴天》- 周杰伦（酷狗）」到面板上；面板以 `--test` 演示
数据也能单独开。三合一入口是 `app.py`。

```
                    ┌──────────────┐
   弹幕面板 ──9701──▶│   点歌机     │──▶ 酷狗/网易云/QQ
  (danmu.py)        └──────────────┘
        ▲                   ▲
        └───── app.py ──────┘   ← 聚合启动器（可选，一起拉起来）
```

| 想干什么 | 命令 |
| --- | --- |
| 两个都要（聚合） | `python app.py` |
| 只要点歌机（无面板） | `python main.py --player-only` |
| 只要弹幕机（无点歌） | `python danmu.py` |
| 只要弹幕机 + 演示弹幕 | `python danmu.py --test` |

面板里每条消息带：**头像 · 昵称（B 站原色）· 大航海/粉丝牌/房管头衔 · 等级 · 时间**，
礼物、上舰、进场等事件用一行高亮显示。

```
┌───────────────────────┐
│ ● 弹幕     拖动/右键关 │  ← 26px 标题条
├───────────────────────┤
│ [头] 昵称 提督 粉丝牌0 20:36:06 │
│      666666                    │
│ [头] 昵称 舰长 粉丝团14 20:36:08 │
│      点歌 晴天                  │
│ 🎁 谁 投喂 小心心×3             │
└───────────────────────┘
```

## 快速开始

需要 Windows + Python 3.8+，以及 **Node.js 18+**（内置酷狗引擎用；装不了也能用，会自动退回网页版）。

```bat
pip install -r requirements.txt
python main.py --gui
python main.py --setup        :: 想重新选「登录 VIP / 只用免费歌」时
```

`--gui` 会弹出小控制窗：填房间号、选面板贴哪边、点「开始」即可。

其它入口：

| 命令 | 作用 |
| --- | --- |
| `python app.py` | **聚合**：点歌机 + 弹幕面板一起起 |
| `python app.py --gui` | 控制窗（推荐日常用），面板和点歌都能从里面开关 |
| `python app.py --no-player` | 只要弹幕面板 |
| `python app.py --no-panel` | 只要点歌机 |
| `python main.py` | 点歌 + 自动拉起弹幕面板（等价于 `app.py`） |
| `python main.py --player-only` | **只跑点歌机**，不开面板 |
| `python main.py --panel` | 只开弹幕面板，不管点歌 |
| `python danmu.py` | **只跑弹幕机**（独立进程，不点歌） |
| `python danmu.py --test` | 弹幕机演示模式（假弹幕，看效果用） |
| `python main.py --setup` | 重新走首次运行向导（酷狗 VIP 登录提示） |
| `python main.py --once 晴天` | 只测一首歌能不能放出来 |
| `python main.py --sources` | 看酷狗/网易云/QQ 三家现在通不通、能搜到什么 |
| `python main.py --offline` | 不连 B 站，用键盘输入模拟弹幕（调试） |
| `python test_all.py` | 离线自测，应输出 `FAILED: 0` |

> 两个进程同时存在时，面板端口只能有一个主人：先开的占着，后开的会在日志里说端口被占，
> 但点歌机本身不受影响（只是推给面板的那行提示或字幕掉了），歌照放。

## 弹幕面板的用法

```bat
python danmu.py --host "哔哩哔哩"        :: 贴到标题含「哔哩哔哩」的窗口上
python danmu.py --host "" --screen 1    :: 不跟窗口，投到第 2 块屏
python danmu.py --host "PotPlayer" --app PotPlayerMini64.exe --side left
python danmu.py --size 620              :: 初始边长 620
python danmu.py --size-mode free        :: 拉伸时宽高各自变（默认 square 保持正方形）
```

### 鼠标操作

| 操作 | 效果 |
| --- | --- |
| 拖标题条 / 任意空白处 | 移动面板（拖到任意屏幕都行） |
| 鼠标移到**上/下/左/右边框**，出现双向箭头后拖动 | 拉高 / 拉矮 / 往左拉宽 / 往右拉宽 |
| 拖**四个角** | 同时改宽高 |
| 右键 / 双击 / `Esc` | 关闭面板 |
| `Ctrl+Alt+D` / `Ctrl+Alt+Q` | 显示隐藏 / 关闭 |

- **宽高可自由调整**：`size_mode` 为 `square` 时，从任意一条边拉伸都保持正方形；
  设成 `free` 后宽高各自独立拉伸（可以拉成细长条）。
- **往左延伸**：抓住左边框往左拖，右侧位置不动，宽度变大；往右延伸同理抓右边框。
- **吸附**：默认正方形边长 = 目标窗口高度，压在目标窗口右边缘内侧，`--side left` 换左边。
  目标窗口移动/缩放时面板自动跟随，直到你亲手拖动过它为止。
- 最小尺寸 `min_width` / `min_height`（默认 260 / 160），`edge_margin` 可让面板与窗口边缘留点缝。
- `config.json → danmu` 可调：`side`、`size_mode`、`size`、`min_width`、`min_height`、
  `edge_margin`、`screen`、`alpha` 透明度、`bg` 底色、`font_size` 字号、
  `max_msgs` 保留多少条、`toggle_hotkey`、`quit_hotkey`。
- 面板是独立进程，通过 `127.0.0.1:9701` 收推送，点歌机重开不影响它：
  ```bat
  python danmu.py --emit "测试一条"
  ```

## 点歌

观众弹幕支持这些写法（大小写/全半角无所谓）：

```
点歌 晴天
点歌：晴天 - 周杰伦
【点歌】起风了 - 买辣椒也用券
来一首《稻香》
!点歌 孤勇者
```

`切歌` / `下一首` / `跳过` / `skip` 直接切歌。

规则（`config.json → live`）：

| 键 | 说明 |
| --- | --- |
| `room` | 直播间房间号（不是主播 UID） |
| `sessdata` | 可选，登录 Cookie，能收到更完整的弹幕 |
| `enabled` | 点歌总开关（关掉就只显示弹幕） |
| `user_cooldown_sec` | 同一人点歌冷却，默认 20 秒 |
| `max_order_len` | 歌名最长字数 |
| `admin` | 管理员昵称/UID 列表，不受冷却限制 |

`config.json → queue`：`gap_sec` 每首间隔、`wait_song_end` 等这首放完再放下一首、
`max_pending` 最多排队几首。

### 三家聚合播放

一条「点歌」会**同时搜三家**，按匹配度混排，再依次取直链，谁先拿到能放的完整版就用谁：

| 源 | 默认端口 | 说明 |
| --- | --- | --- |
| 酷狗 | `4000` | 内置在 `vendor/kugou-api/`，程序自己拉起，不用额外装 |
| 网易云 | `3000` | 你自己的 `api-enhanced`；不在线就跳过 |
| QQ音乐 | `3300` | 你自己的 `QQMusicapi`；没登录时能搜不能放（回「无权限/需要 VIP」） |

`config.json → music`：

| 键 | 说明 |
| --- | --- |
| `order` | 优先顺序，默认 `["kugou","netease","qq"]` |
| `per_source` | 每家取几条候选，默认 6 |
| `try_limit` | 最多试几次取直链 |
| `netease` / `qq` | 各自的 `enabled` / `host` / `port` |

本机端口跟默认不一样时，写进 `config.local.json`（会被覆盖加载，不会动到分发的 `config.json`）：

```json
{ "music": { "netease": { "port": 3001 }, "qq": { "port": 3301 } } }
```

看三家现在通不通：

```bat
python main.py --sources
python main.py --sources --once 晴天
```

**兜底规则**：酷狗搜到的那条恰好是 VIP 歌、取不到直链时，会自动去网易云/QQ 找同名的免费版，
所以「周杰伦原版放不了」通常会变成「放一个同名的翻唱完整版」，而不是直接报错。

### 酷狗播放是怎么实现的

默认走**内置酷狗引擎**（本地 API，`127.0.0.1:4000`），完全不碰浏览器：

1. 启动时探测 `127.0.0.1:4000`，没有就自动拉起 `vendor/kugou-api/`（需要机器上有 Node.js）。
2. 首次运行自动向酷狗登记一个**设备指纹 `dfid`**（`/register/dev`）。这一步很关键——
   没登记过的设备去取播放地址会被回 `20028 本次请求需要验证`，连免费歌都放不了。
   登记时必须带上一个稳定的设备 `uuid`（放在 Cookie 的 `KUGOU_API_GUID` 里），
   否则接口会返回空 `data`。拿到的 `dfid`/`uuid` 会写进 `config.local.json` 长期复用。
3. 搜索 → 打分挑歌 → 取直链 → 下载到 `~/.danmuji/cache/` → 用 `winsound` 本地播放。
   下载下来小于 24KB 的（酷狗对无版权曲目常给一个占位音）直接判失败，换下一首。

取不到直链时才退回**网页版**：用 CDP 开一个独立 profile 的 Edge/Chrome（端口 `9333`）。

> **免费 / 付费**：免费歌返回完整版；付费歌无 VIP 时只返回 60 秒试听片段。
> 程序会自动跳过试听、先找同名的免费完整版（比如周杰伦原版不行就放翻唱完整版）；
> 实在只有试听就播试听并提示一次。想听原版完整曲目 → 登录酷狗 VIP。

### 首次运行的 VIP 提示

第一次启动会弹出提示（`python main.py --setup` 可再次调出）：

```
目前已部署完毕，但只支持免费歌曲。

如果你点歌需要付费歌曲的话，请登录你的酷狗VIP账号。
```

- 选 **是（Y）**：弹出二维码，用酷狗 App 扫码登录，登录态存在本地。
- 选 **否（N）**：跳过，只用免费歌曲。
- 选择结果记在 `config.local.json` 的 `kugou_api.setup_done`，之后不再打扰。

## 分发给别人 / 杀软误报

- 全部是**纯 Python 源码**，`pip install` 后直接跑，不打包 exe —— 这是最不容易被误报的形态。
- 不写注册表、不装服务、不加自启动；后台只有本机的 `127.0.0.1:9701`（面板）、
  `127.0.0.1:4000`（酷狗引擎）和按需的 `9333`（网页版兜底）。
- 外连域名只有：`api.bilibili.com`、`live.bilibili.com`、`songsearch.kugou.com`、
  `www.kugou.com`、`userservice.kugou.com`、`fs.youthandroid*.kugou.com`（音频 CDN）。
- **酷狗引擎只监听 127.0.0.1，不需要公网、不需要隧道**。点歌机和它是同一台机器上的两个进程，
  走回环地址就够了。每台机器首次运行会各自领一个设备指纹，互不影响。
- 如果一定要打包成 exe：用 PyInstaller **不开 UPX、不混淆**，体积大一点的「一体式」包反而更少被报毒；
  发出去之前先传到 VirusTotal 看看，别用在线「加壳」服务。
- 别把带你自己 `sessdata` / 酷狗登录态的 `config.local.json` 发给别人。

## 常见问题

- **面板没出现**：目标窗口标题没匹配上（`--host` 是子串匹配），或窗口被最小化；
  不跟窗口时用 `--screen 0` 固定到屏幕。
- **点歌没声 / 提示「本次请求需要验证」**：设备指纹失效或被限流。删掉 `config.local.json`
  里的 `kugou_api.dfid` 再启动，会自动重新登记一个；连续失败就等 90 秒。
- **三家只有一家在**：`python main.py --sources` 看哪个红了。网易云/QQ 是你另装的 API，
  没开就跳过（不影响点歌，酷狗能顶上）；端口不是默认的写进 `config.local.json` 的 `music` 段。
- **QQ 显示「无权限 / 需要 VIP」**：没登录 QQ。能在三家搜到，但 QQ 那条取不到直链时
  程序会自动去酷狗/网易云找同名的，通常还是有声的。
- **提示「只有试听片段」**：这首是付费歌，免费额度只给 60 秒。用 `--setup` 登录酷狗 VIP。
- **没有 Node.js**：内置引擎起不来，会自动退回网页版（效果差一些，付费歌可能完全放不了）。
- **端口被占用**：面板 9701、酷狗引擎 4000、网易云 3000、QQ 3300、网页版调试口 9333，
  都在 `config.json` / `config.local.json` 里可改。
